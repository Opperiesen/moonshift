# Code of Conduct

Moonshift aims to be a welcoming, respectful, and constructive open-source project. We adopt the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as our code of conduct.

Project participants are expected to follow its standards in issues, discussions, reviews, commits, and other project spaces. Please report unacceptable behavior privately to the maintainers through the project's current private reporting channel. Because Moonshift is pre-publication, that channel has not yet been published here; do not infer or invent an email address.

Enforcement procedures and contact details will be finalized before public launch. This file provides attribution and a link to Contributor Covenant 2.1; it does not grant or add a software license.
